1. Introduction

Welcome to Social Intelligence Desk.

Social Intelligence Desk is an independent software project developed and operated by an individual developer.

The application is designed to help users organize, manage, and analyze social media information obtained through authorized sources.

We respect privacy and are committed to handling personal information responsibly.

This Privacy Policy explains the data practices associated with our website and macOS desktop application.

2. Information We Process

Depending on how the application is used, the following categories of information may be processed:

  • Social media usernames and profile information.
  • Publicly available account descriptions and metadata.
  • Video titles, descriptions, and associated metadata.
  • Comment records and engagement information.
  • User-provided files and imported datasets.
  • Application settings and locally stored records.
  • Information voluntarily provided when contacting us.

Users are responsible for ensuring they have the necessary rights and permissions to import and process their selected data.

3. Sources of Information

The current application supports information provided directly by users through manual entry or file imports.

Supported formats include CSV, XLSX, and JSON.

Future versions may support authorized third-party APIs and official platform integrations, subject to applicable permissions.

The current application does not automatically collect data from TikTok through an active TikTok API integration.

Any future integration will be implemented according to applicable platform requirements and authorized data access permissions.

4. How Information Is Used

Information processed through the application may be used for:

  • Organizing social media account records.
  • Managing video and comment information.
  • Classifying content and account categories.
  • Searching and filtering imported datasets.
  • Maintaining records and data integrity.
  • Generating reports from user-managed information.
  • Supporting authorized data analysis workflows.

We do not represent unverified personal attributes or automated estimates as confirmed facts.

5. Local Data Storage

Social Intelligence Desk is designed as a local-first desktop application.

Application records are stored in a local SQLite database on the user's device.

The application does not automatically upload the complete local database to our website.

Users are responsible for protecting their devices, managing access to local files, and maintaining appropriate backups.

Local records remain on the user's device unless the user chooses to export or otherwise transmit information.

6. Third-Party Services

Our public website is hosted using GitHub Pages.

GitHub may process technical information associated with website access according to its own privacy practices.

Please review the GitHub Privacy Statement for additional information.

The desktop application includes an option to securely store an OpenAI API key using the macOS Keychain.

Automated OpenAI-powered analysis workflows are planned for future development.

Before introducing new data transfers, we intend to update this policy to explain the relevant processing and service providers.

7. Data Sharing

We do not sell personal information collected through our website.

We do not operate a centralized database containing all customer records stored locally by application users.

Information may be disclosed when required by applicable law or when a user explicitly authorizes a relevant data transfer.

Any future sharing associated with API integrations or AI processing will be subject to applicable permissions and updated disclosures.

8. Data Retention

Records imported into the desktop application are generally retained in the user's local database until the user deletes them.

Users should manage their own retention periods and delete records that are no longer necessary.

Email inquiries are retained only as reasonably necessary to respond, maintain relevant correspondence, or meet applicable legal obligations.

9. Data Security

We take data security seriously.

The application is designed to use local database storage and the macOS Keychain for supported credential storage.

However, no software or storage system can guarantee absolute security.

Users should maintain appropriate device security, software updates, and local backup practices.

10. Your Privacy Rights

Depending on applicable laws, individuals may have rights relating to access, correction, deletion, or other processing of their personal information.

For information held directly by the website operator, you may contact us using the email below.

For data stored exclusively in a user's local desktop database, the user controls that local copy.

We may not have access to records stored solely on another person's device.

11. Children's Privacy

Social Intelligence Desk is not designed for children under the age of 13.

We do not knowingly operate a service intended to collect personal information directly from children under 13.

12. Changes to This Policy

We may update this Privacy Policy as the application develops or applicable requirements change.

Updated versions will be published on this website with a revised effective date.

13. Independent Application

Social Intelligence Desk is an independent software project.

It is not affiliated with, endorsed by, or officially sponsored by TikTok.

Any future access to TikTok services will depend on applicable authorization and platform approval.
