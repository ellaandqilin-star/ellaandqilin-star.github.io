About Our Application

Social Intelligence Desk is a desktop software project designed to help users organize social media account information, video metadata and comment records.

The application uses local data storage and supports structured data management.

Current Features

Account Management

Organize account profiles, public metrics and data sources.

Data Import

Import authorized data using CSV, XLSX and JSON files.

Local Data Storage

Manage application records using a local SQLite database.

Planned Integrations

Authorized API integrations and AI-assisted content analysis are planned for future releases.
